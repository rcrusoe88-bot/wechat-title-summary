# 主题一：学术机制图风 — 文生图 prompt 设计规格

参考来源：植生笔记公众号封面设计风格（学术期刊配图审美）
适用比例：21:9（7:3）横版，推荐渲染尺寸 1260 × 540px

---

## 设计哲学

学术机制图风的核心是「克制」——去掉所有非必要的装饰，让生物分子本身的形态和色彩成为视觉焦点。参考 Nature/Cell 系列期刊的图注风格：纯白背景、矢量有机形状、固定5色科学配色系统、细线箭头、无阴影无描边框。

读者一眼看到封面，应该感受到「这是一篇有实验数据支撑的专业内容」，而不是「这是一张精心设计的海报」。

---

## 色彩系统（固定，不随文章调整）

这5色来源于学术机制图中蛋白质/结构域的标准配色系统，覆盖暖冷中性色调，搭配协调且具有识别度：

| 色号 | 色值 | 用途 |
|------|------|------|
| 玫瑰粉 | `#BD7C78` | 主要蛋白结构域A、信号蛋白 |
| 天蓝 | `#B0D7E9` | 受体、通道蛋白、效应蛋白 |
| 紫 | `#7767A1` | 复合体核心蛋白、调控蛋白 |
| 金 | `#D9BE67` | 配体、小分子、代谢产物 |
| 绿 | `#62B187` | 正向信号蛋白、激活型效应分子 |
| 主文字 | `#2C2C2C` | 全局正文、标题 |
| 次要标注 | `#555555` | 机制图节点标注 |
| 分割线 | `#C8C8C8` | 区域分隔细线 |
| 正向标签背景 | `#EAF4EC` | 如"Resistance"类标签 |
| 正向标签文字 | `#2E7D52` | — |
| 警示标签背景 | `#FDECEA` | 如"Cell death"类标签 |
| 警示标签文字 | `#C0392B` | — |

**prompt 中必须明确写出这些色值**，不允许引入色系外颜色。

## 三栏布局描述规范

prompt 中需要用自然语言精确描述三栏布局：

### 左栏（30%宽度）— 文字信息区
- 顶部：来源标注（期刊名+年份，斜体灰色小字）
- 中部：文章主标题（大字加粗，2-3行）
- 底部：核心结论副标题（灰色小字）
- 最底：5色色板圆形横排展示

### 中栏（45%宽度）— 机制通路图区
- 3-5个有机 Blob 形状节点（代表蛋白/分子）
- 箭头连接（实心三角箭头，灰色细线）
- 虚线箭头表示推测步骤
- 节点下方小字标注名称
- 末端可有标签盒（绿底正向/红底负向）

### 右栏（25%宽度）— 蛋白结构展示区
- 3-4色叠压有机 Blob 蛋白复合体
- 蛋白名称标签
- 底部公众号名灰色小字

## 关键视觉元素描述词汇

在 prompt 中描述以下元素时，使用对应的英文关键词：

| 元素 | prompt 描述关键词 |
|------|------------------|
| 蛋白 Blob | "organic blob shape, smooth Bézier curves, no outline stroke, overlapping layers" |
| 化学分子 | "irregular hexagon, thin purple stroke, light fill, small molecular structure" |
| 实心箭头 | "thin gray arrow with solid triangle arrowhead, clean vector line" |
| 虚线箭头 | "dashed arrow, stroke-dasharray pattern, indicating hypothetical pathway" |
| 标签盒 | "small rounded-rect tag box, colored background, short text label" |
| 色板 | "row of 5 small colored circles, palette swatch display" |
| 蛋白复合体 | "layered organic blob protein complex, 3-4 overlapping colored shapes, no borders" |

## 禁止项（必须写入 negative prompt）

- 渐变背景（径向渐变、线性渐变）
- 阴影效果（drop shadow、box-shadow）
- 蛋白 Blob 上的描边轮廓
- 色系外颜色
- 装饰性几何图形（圆圈、三角、矩形背景块）
- 手写字体或粗装饰字体
- 3D 渲染、照片级写实
- 暗色背景、霓虹色
- 水印

---

## prompt 构建模板

组装 prompt 时，按以下顺序组织内容：

1. **画幅与比例**：开头明确 21:9 比例和尺寸
2. **整体风格**：学术期刊机制图、白底、矢量插画
3. **三栏布局描述**：左-中-右，每栏内容
4. **色彩指定**：5色色值 + 文字色 + 标签色
5. **视觉元素细节**：Blob 形状、箭头、标签盒等
6. **字体提示**：Noto Sans SC、学术感
7. **Negative prompt**：排除不想要的风格

---

## 内容填充规则

| 文章元素 | prompt 中的映射 |
|---------|----------------|
| 核心蛋白A | 右栏主体有机 Blob，使用主色（玫瑰粉/紫） |
| 核心蛋白B | 右栏叠压层，使用次色（天蓝/绿） |
| 关键配体/小分子 | 右栏最小结构域，使用金色 |
| 通路起点→终点 | 中栏机制图，3-5节点线性或分叉展示 |
| 最重要数据 | 左栏副标题直接呈现（如「效率提升8.3倍」） |
| 论文期刊 | 左栏顶部来源标注，期刊名斜体 |
| 正向/负向结论 | 中栏末端标签盒（绿底正向/红底负向） |
