# 标题模式库

本文件存储各类标题模式的完整示例库，供生成时参考对照。

---

## 模式一：报道型

**句式**：`[机构/人物] + [动作词]：[具体发现]`

**核心要求**：机构/人物名必须出现，动作词要有力，发现内容要具体到数据或对比。

**强力动作词库**：
- 重磅文章 / 发表 / 披露 / 揭示 / 证实 / 报道
- 最新发现 / 首次证明 / 重新定义

**完整示例**：
- `Moderna重磅文章：降低核糖体负载，稳定mRNA，增加蛋白总产出`
- `Capstan创始人最新发现：aCD7-tLNP最强T细胞靶向递送由内化效率决定，而非受体丰度`
- `BioNTech披露：脂质尾链不饱和度每提升1级，内体逃逸效率提升23%`
- `MIT团队证实：pH响应型LNP在肿瘤微环境中释放效率是正常组织的4.7倍`
- `Intellia Therapeutics报道：体内基因编辑单次给药，12个月随访肝脏靶基因沉默率>85%`

**易犯错误**：
- ❌ `某团队发现了LNP的新特性` — 动作词弱，发现内容泛泛
- ❌ `关于mRNA递送的重要研究` — 无机构、无具体内容
- ✅ `Precision BioSciences首次报道：碱基编辑器C→T转换效率突破90%，脱靶率<0.1%`

## 模式二：叙事型

**句式**：`从[旧认知/旧方法]到[新突破]，[主体]终于/正在[转变动词]`

**核心要求**：旧→新的对比要鲜明，主体明确，转变有情感张力。

**转变动词库**：
- 终于 / 开始 / 正在 / 彻底 / 悄悄 / 不得不

**完整示例**：
- `从死磕脂质到调控细胞，LNP研发终于跳出了十年惯性`
- `从随机包裹到精准组装，mRNA-LNP的下一个十年已经开始`
- `从体外验证到体内闭环，CAR-T自动化制造正在重写临床规则`
- `从单靶点到多靶联合，肿瘤免疫治疗彻底告别"单兵作战"时代`
- `从冷冻保存到常温递送，mRNA疫苗分发最后一公里难题正在瓦解`

**变体（不用"从...到..."结构）**：
- `LNP研发的十年惯性，正在被一篇论文打破`
- `mRNA递送不再只是脂质的事：细胞生物学视角如何重塑整个领域`

**易犯错误**：
- ❌ `mRNA技术不断进步，未来可期` — 无具体转变，情感空洞
- ✅ `从效率2%到突破20%，内体逃逸的瓶颈终于有了系统性解法`

## 模式三：问句型

**句式A**：`[技术方案]能否/是否适合[应用场景]？`
**句式B**：`[A]比[B]更适合做[C]吗？`
**句式C**：`[数量词][类型]，[主体]该怎么选？`

**核心要求**：问题必须对从业者有实际决策价值，不能是自问自答的修辞问句。

**完整示例**：
- `高盐沉淀+TFF换液的mRNA纯化工艺适合中试生产吗？`
- `In vivo CAR-T竞速：mRNA-LNP能否成为自身免疫性疾病"终局疗法"的关键平台？`
- `iLNP还是pLNP，哪种结构更适合肝外组织靶向？`
- `五种电离脂质，2025年做肿瘤mRNA疗法该怎么选？`
- `环状RNA vs 线性mRNA：免疫原性差异真的决定了临床命运吗？`
- `GMP级别mRNA纯化用Oligo dT还是HPLC？一篇文章给你答案`

**易犯错误**：
- ❌ `mRNA疫苗是否有效？` — 问题无决策价值，非从业者视角
- ✅ `mRNA-LNP肌注后的淋巴结蓄积是"副作用"还是"免疫佐剂"？`

## 模式四：观点型

**句式A**：`[主体]不再[旧做法]：[新趋势]，才是[核心判断]`
**句式B**：`你必须知道的[技术主题]：[具体判断]`
**句式C**：`[主体]的[时代转折点]：[具体内容]`

**核心要求**：观点要有争议性或反直觉性，不能是显而易见的常识。

**完整示例**：
- `LNP不再讲平台：应用，才是新的分水岭`
- `你必须知道的mRNA稳定化策略：5'UTR结构，才是被低估的关键变量`
- `CAR-T制造的转折点：从患者到通用，这一步比想象中更近`
- `mRNA疗法不再只是疫苗的事：肿瘤、罕见病、再生医学，三条赛道正式开跑`
- `LNP的边界正在消失：脂质体、外泌体、聚合物纳米粒，谁会赢得下一个十年？`

**变体（强判断词）**：
- `被严重低估的 [技术点]：[理由]`
- `[行业共识] 可能是错的：[新证据]`

## 模式五：方法链型

**句式**：`基于[技术A]，[操作B]，实现[目标C]`

**核心要求**：三个环节必须是技术上有因果关系的连贯动作，不能是并列罗列。

**完整示例**：
- `基于AI设计适配体，偶联至LNP表面，实现肿瘤靶向递送`
- `基于冷冻电镜解析结构，优化电离脂质构型，将内体逃逸效率提升3倍`
- `通过修饰核苷酸m1Ψ，降低mRNA免疫原性，实现体内长效蛋白表达`
- `利用微流控精准控制水动力学直径，获得均一LNP，提升批间重复性`
- `基于高通量筛选文库，发现新型可电离脂质，突破肝外靶向瓶颈`

**易犯错误**：
- ❌ `研究了mRNA结构、脂质配方和工艺参数` — 并列罗列，无因果链
- ✅ `通过优化CDS密码子使用，配合ARCA帽子类似物，将体外翻译效率提升2.4倍`

## 标题强词速查表

| 类型 | 词汇 |
|------|------|
| 强化 | 重磅、首次、终于、关键、颠覆、突破、里程碑、新动向 |
| 对比 | 而非、不再…而是…、从X到Y、舍弃X转向Y、超越 |
| 问句 | 能否、是否、适合吗、比X更好吗、该怎么选 |
| 读者感知 | 你必须知道的、不得不看的、被低估的、被忽视的 |
| 时间感 | 2025年、下一个十年、正在、已经、终于 |

## 禁止词列表

以下词汇在任何标题中均禁止使用（过于泛泛）：
- 新进展、重要研究、相关工作、最新动态、深度解析（单独使用时）
- 值得关注、引人注目、意义重大
- 领域、方向、方面（作为结尾词）
