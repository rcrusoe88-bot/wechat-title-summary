# 公众号标题与摘要风格指南

本文件基于博主已发表文章提炼，供生成标题和摘要时参考对照。

---

## 一、标题风格分类与示例

### 类型一：报道型（最常见）
**模式**：`[机构/人物] + [事件标签]：[核心发现/转变]`

| 原文标题 | 核心结构 |
|---------|---------|
| Capstan创始人最新发现：aCD7-tLNP最强T细胞靶向递送由其内化效率决定，而非受体丰度 | 人物+最新发现：结论A，而非B（对比） |
| Moderna重磅文章：降低核糖体负载，稳定mRNA，增加蛋白总产出 | 机构+重磅文章：动词+目标1，动词+目标2 |
| 强生RSV疫苗新动向：舍弃腺病毒载体疫苗后，转向自复制RNA疫苗 | 机构+产品+新动向：从A转向B |

**关键词库**：重磅文章、最新发现、新动向、首次证实、新突破

---

### 类型二：叙事型
**模式**：`从[旧认知/旧方法]到[新突破]，[主体]终于[完成转变]`

| 原文标题 | 核心结构 |
|---------|---------|
| 从死磕脂质到调控细胞，LNP研发终于跳出了十年惯性 | 从X到Y，主体终于完成Z |
| AACR 2026｜LNP不再讲平台：应用，才是新的分水岭 | 会议标签｜主体不再X：Y，才是Z |

**关键词库**：终于、不再…而是…、从X到Y、跳出、迎来

---

### 类型三：问句型
**模式**：`[技术/方案] + 能否/是否/适合/比X更好吗？`

| 原文标题 | 核心结构 |
|---------|---------|
| 高盐沉淀+TFF换液的mRNA纯化工艺适合中试生产吗？ | 技术方案+适合+应用场景+？ |
| In vivo CAR-T竞速：mRNA-LNP能否成为自身免疫性疾病"终局疗法"的关键平台？ | 领域赛题：技术能否成为X？ |
| 无帽无修饰线性mRNA比修饰CAP1 mRNA更适合开发肿瘤疫苗吗？ | A比B更适合做C吗？ |

**关键词库**：能否、是否、适合吗、比X更好吗、竞速、终局

---

### 类型四：观点/洞察型
**模式**：`你必须知道的[主题]` / `[主体]不再[旧做法]：[新判断]`

| 原文标题 | 核心结构 |
|---------|---------|
| 你必须知道的mRNA疫苗5'UTR序列筛选流程 | 你必须知道的+具体技术主题 |
| LNP不再讲平台：应用，才是新的分水岭 | 主体不再X：Y，才是Z |

**关键词库**：你必须知道的、不得不了解的、才是真正的分水岭

---

### 类型五：方法链型
**模式**：`基于[技术A]，[操作B]，实现[目标C]`

| 原文标题 | 核心结构 |
|---------|---------|
| 基于AI设计适配体，偶联至LNP表面，实现靶向递送 | 基于A→B→实现C（三步递进） |

## 二、标题写作规范

### ✅ 应该做
- 保留英文专业术语原文：mRNA、LNP、CAR-T、tLNP、UTR、saRNA、NHP 等
- 使用对比结构增强冲击力：`而非`、`不再…而是…`、`舍弃X转向Y`
- 有具体数字时纳入标题：`提升80倍`、`5-20倍`、`三期临床`
- 机构/人物作为信源时前置：`Moderna`、`强生`、`Capstan创始人`

### ❌ 避免做
- 泛泛而谈：`新进展`、`重要研究`、`新发现`（无具体内容）
- 把英文术语翻译成中文俗称（如把 mRNA 写成"信使核糖核酸"）
- 超过 40 字（含标点）

## 三、摘要写作规范

### 结构模板（2-3句）

```
第一句：[来源机构/期刊/会议] + 发文/发现，[研究背景一句话]
第二句：[核心发现/结论] + [关键数据支撑]
第三句（可选）：[行业意义 / 局限性说明]
```

### 示例对照

**文章**：Moderna核糖体负载研究
**摘要**：Moderna在《Cell Reports》发文，系统揭示CDS序列密码子适应性与mRNA半衰期的量化关系。研究发现高核糖体密度反而加速翻译依赖性降解，适度核糖体负载（每170nt约1个）才能最大化蛋白总产出。该结论直接指导治疗性mRNA的CDS序列优化设计。（92字）

**文章**：强生saRNA RSV疫苗
**摘要**：强生杨森团队在《Nature Communications》发文，首次在小鼠和NHP中证实自复制RNA RSV疫苗单剂1-10μg可触发与蛋白亚单位疫苗相当的中和抗体，且额外激活蛋白疫苗无法诱导的多功能Th1偏向T细胞。但目前缺乏头对头比较数据与保护效力数据。（108字）

**文章**：AI适配体偶联LNP
**摘要**：AtomBio团队在bioRxiv发文，将AI设计的适配体Apt62偶联至LNP表面，靶向CD4+T细胞。Apt62LNP使SM102 LNP脾脏摄取率提升80倍，体内安全性良好，成本优于抗体偶联LNP，为In vivo CAR-T递送提供新选择。（97字）

### ✅ 摘要应该包含
- 来源机构 + 发表期刊/平台
- 核心结论（"发现"、"证实"、"首次"、"提出"）
- 具体数据（倍数、百分比、浓度、剂量）
- 如有局限性，简要说明

### ❌ 摘要避免
- 只说"研究了什么"，不说"发现了什么"
- 超过 50 字（含标点）（摘要面向读者一句话抓重点，无需展开背景）
- 解释基础概念（读者是从业者，无需科普）
- 堆砌形容词而缺乏实质内容

## 四、领域术语表（保持英文原文）

|------|------|
| mRNA | 信使RNA，不翻译 |
| LNP | 脂质纳米颗粒 |
| tLNP | 靶向LNP |
| CAR-T | 嵌合抗原受体T细胞 |
| In vivo CAR-T | 体内CAR-T |
| saRNA | 自复制RNA |
| UTR | 非翻译区（5'UTR / 3'UTR） |
| NHP | 非人灵长类 |
| CDS | 编码序列 |
| IVT | 体外转录 |
| TFF | 切向流过滤 |
| PBMC | 外周血单核细胞 |
| CMC | 化学、制造和控制 |
